# Srinath Kishore — Portfolio

My personal site, live at **[srinathkishore.github.io](https://srinathkishore.github.io)**.

I'm a Systems Development Engineer at Amazon, and a backend & AI engineer who somehow tripped into the code world. This is where I keep the short version: who I am, where I've worked, the things I've built, and what I do when nothing is on fire.

A small hand-drawn planet follows you down the page and turns to show where each part of the story happened. Try messing up my name on the first screen. There may be a cheat code or two.

## What's inside

- Plain HTML, CSS and JavaScript, no framework and no build step
- A WebGL planet drawn entirely in a shader
- Live chess.com and LeetCode stats, refreshed daily by a GitHub Action
- Light and dark themes, and a lighter mode for slower devices

## Run it locally

```sh
npx serve .
```
